# 🎬 Presentador de Diapositivas Web

Aplicación web para presentaciones multimedia con transiciones animadas.

## ✨ Características

- 🖼️ Soporte imágenes y videos
- 🎨 13 efectos de transición CSS
- ⌨️ Navegación teclado/flechas
- 📱 Diseño responsive full-screen
- 🎯 Indicadores de progreso visuales

## 🚀 Uso Rápido

1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. Edita el array `mediaItems` en el script para tus contenidos

## 🛠️ Tecnologías

- HTML5
- CSS3 (Animaciones)
- JavaScript (ES6+)
